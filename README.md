# Desenvolupament Web

## Overview

This repository contains the exercises completed during the **Desenvolupament Web** stage of my programming studies.

The objective of this stage was to gain an understanding of modern web application development and explore the different specialization paths available in the industry, including **Frontend**, **Backend**, and **Full Stack** development.
